### 1. LIN YEAN — Overload Profile
**OMEGA ESPER / COMBAT UNIT**

- เอสเปอร์ระดับ S โดยเก่า ควบคุมพลังความเย็น Absolute Zero
- ความเสี่ยง: **Absolute Overload** (พลังสิ้นตัวคน)

| ขั้น | ชื่อ | อาการ |
|---|---|---|
| STEP 0 | STABLE | ควบคุมอุณหภูมิสมดุล / เรโซแนนซ์นิ่งมาก / จิตใจสมดุล |
| STEP 1 | INSTABILITY | อุณหภูมิรอบตัวลดลง / ไอเย็นออกจากร่างกาย / ความมั่นเริ่มสั่นคลอน / สมาธิส่งสูง |
| STEP 2 | RESONANCE BREAK | พื้น/นิ้งเกิดน้ำแข็ง / ตัดสารเริ่มเหลือความควบคุม / ได้ยินเสียงนายายกลอด / เรโซแนนซ์แกร่งขึ้น 50–70% |
| STEP 3 | PRE OVERLOAD | Absolute Zero ทำงานเอง / ทุกอย่างที่เข้าใกล้เป็นภัย / Mental Field ปกคลุมส่วน / เรโซแนนซ์พุ่งสูง 70–90% |
| STEP 4 | **COLLAPSE** | กลายเป็น "อาวุธ" / ไม่รู้จักมิตร/ศัตรู / พลังทำลายล้างไม่สามารถควบคุม / เสี่ยงต่อการเป็น FALLEN ESPER |

**สัญญาณเตือนเฉพาะ (LIN YEAN):** อุณหภูมิลดลง / ไอน้ำเย็น / ควาตัด / เรโซแนนซ์พุ่ง / ดีตารับรู้

```
EXECUTIVE BOARD (คณะบริหาร)
        ↓
COMMAND CENTER (ศูนย์บัญชาการ)
```

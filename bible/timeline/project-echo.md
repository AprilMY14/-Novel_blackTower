# Project Echo Timeline

## Approved Stable Facts

- Project Echo occurred 10 years ago.
- The project was located at Black Tower Lab B4.
- Pair-00 was the experimental focus of the project.
- A resonance spike occurred during the experiment sequence.
- Memory Lock was implemented after the incident.
- Han Yicheng approved the implementation of Memory Lock after the Project Echo incident.
- Lin Yien was affected by Memory Lock and lost all memories of the Project Echo events and all relationships connected to Project Echo.
- Other people involved in the Project Echo incident did not survive or were lost in the accident and are not established as surviving participants.
- The project was terminated.
- Records related to the incident were sealed or suppressed.

## Scope

This record includes only the established, non-speculative sequence of the incident. It does not include hidden or true cause, Pair-00 survival status, the exact identities or number of other deceased/missing participants, or the Memory Lock mechanism beyond the approved effect on Lin Yien.

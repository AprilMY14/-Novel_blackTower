# Project Echo Timeline

## Canon Status

This file contains only the currently approved conservative canon for Project Echo.

Details found in legacy planning files, old steering notes, audits, or reference material must not be promoted into canon unless explicitly approved by the human maintainer.

## Approved Stable Facts

- Project Echo was a secret project.
- The project was located at Black Tower Lab B4.
- The main incident occurred approximately 10 years ago.
- Pair-00 was the experimental focus of the project.
- A resonance spike occurred during the experiment sequence.
- The project was terminated.
- Records related to the incident were sealed or suppressed.
- A Memory Lock protocol was used after Project Echo.
- Memory Lock is a memory-restriction protocol.
- Lin Yien has a memory gap concerning Project Echo.
- Lin Yien does not remember the Project Echo events or the relationships connected to Echo.

## Unresolved / Hard Boundaries

The following are intentionally unresolved and must not be invented:

- The cause, nature, origin, intention, or mechanism of Black Signal.
- Pair-00 survival or current status.
- Pair-00 identities, abilities, resonance percentages, or detailed relationship data.
- The authority that ordered or approved Memory Lock.
- The person or persons who implemented Memory Lock.
- The mechanism of Memory Lock.
- The exact target and scope of Memory Lock.
- Which specific memories were removed or restricted beyond the approved Lin Yien memory-gap statement.
- Other people involved in Memory Lock.
- Han Yicheng's role, history, motive, institutional position, or relationship to Project Echo, Pair-00, Chen Yu, or Memory Lock.
- Chen Yu's historical career or hidden role in Project Echo.

# Final Workflow Core

This is the compact operational core for the project.

Every agent must read these files before beginning new work:
- AGENTS.md
- PROJECT_WORKFLOW.md
- agent-guardrails.md
- chapter-preflight-checklist.md

---

## 1. Core purpose

The project uses two roles:
- Codex = planning and canon design
- Gemini = writing and Bible conversion

The workflow is designed to prevent drift, wrong-agent work, and accidental edits to protected files.

---

## 2. Required operating rules

### Before any work
1. Read AGENTS.md
2. Read PROJECT_WORKFLOW.md
3. Read agent-guardrails.md
4. For chapter work, complete chapter-preflight-checklist.md
5. Only then begin work

### For chapter work
Gemini must confirm:
- I have read AGENTS.md
- I have read PROJECT_WORKFLOW.md
- I have checked the relevant Bible section
- I have checked previous chapter continuity if needed
- This is chapter drafting, not workflow editing
- I am writing only inside kiro/chapters/
- I am not editing protected workflow files
- I am not editing Codex planning files
- I have approved plot reference for this chapter
- I am not inventing new canon without review
- I have completed the final preflight confirmation

---

## 3. Protected files

These files are not free-edit zones:
- AGENTS.md
- PROJECT_WORKFLOW.md
- agent-guardrails.md
- chapter-preflight-checklist.md

If a task attempts to modify these files, it must stop and request maintainer approval.

---

## 4. Ownership

### Codex owns
- plot
- premise
- worldbuilding
- story structure
- canon decisions

### Gemini owns
- chapter writing
- scene execution
- prose
- Bible conversion from legacy material

---

## 5. Legacy material rule

Legacy or Old files are archive reference only.
Once converted to .md working records, they become review-only material.
They are not active canon unless explicitly re-approved.

---

## 6. Final rule

The project should stay compact and strict:
- do not over-produce workflow files
- keep the active operating set small
- use preflight checks for chapter work
- keep review and approval explicit

This is the final compact operating core for the project.

# Gemini Bible Working Area

This folder is the working conversion area for legacy material and Old files.

Purpose:
- transform old draft material into clean, reusable story Bible entries
- organize information by group
- prepare final canonical records for the project
- create a structured, readable reference before chapter writing continues

## Ownership
This folder belongs to Gemini.

## Workflow
1. Review Old files and legacy notes.
2. Extract relevant information.
3. Sort into the correct group folder.
4. Write structured .md or .yaml files.
5. Promote approved records into the root bible/ when they are stable.

## Groups
- characters/
- factions/
- locations/
- timeline/
- world/
- relationships/

## Rule
Old files remain a historical reference. The working Bible here is the cleanup layer before the project canonical bible is updated.
